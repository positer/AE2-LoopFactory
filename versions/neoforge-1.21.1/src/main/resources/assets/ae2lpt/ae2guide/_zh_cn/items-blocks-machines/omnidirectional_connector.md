# 全向连接器

<BlockImage id="ae2lpt:omnidirectional_connector" scale="6" />

<RecipeFor id="ae2lpt:omnidirectional_connector" />

右键打开频道配置页，创建或选择命名连接频道。同一频道内所有已加载的连接器连接到一个 AE2 原生虚拟节点，支持跨维度。连接面、放置方向和几何形状沿用无线访问点，外壳、灯光、物品和粒子中的紫色细节全部改为白色。

连接器不消耗 AE 能量，也不占用设备频道；传递的频道仍由 AE2 原生寻路与容量规则分配。网络接入超算合成优化接口后，容量翻倍一次，不随超算数量叠加。连接器不会强制加载区块，卸载或拆除时断开对应虚拟连接。

无线访问点、循环水晶与缠绕态奇点无序合成，产出四个连接器。使用 AE2 扳手拆卸时，返回的连接器物品保留已选择的连接频道。


已连接频道且处于 AE2 原生在线状态时，连接器发出缓慢向外扩散的白色小粒子，轨迹限制在自身单方块内；解绑或离线后停止。该特效不增加 AE 能耗。

## 部署无线工厂网络分发结构

连接器的基座（安装）面可以朝任意方向。工厂网络只凭结构接入；所选频道只承载 AE 网络。

| 放置方式 | 工厂无线 | AE 网络 |
| --- | --- | --- |
| 基座贴在循环工厂网络终端的**顶面** | 是：接入该终端的工厂网络 | 选了频道时，终端网络接入频道 |
| 基座贴在工厂样板供应器的**子网（朝向）面** | 是：接入该供应器的子网 | 选了频道时，供应器的**主网**接入频道；子网永远不接入 |
| 基座贴在终端或供应器的其他面 | 否 | 连接器仍通过基座面接入自己的频道 |

1. 先放终端或供应器，再把连接器的基座面贴到对应的面上。
2. 连接器方块内部出现白色环绕粒子，表示工厂结构已成型。
3. 需要同时承载 AE 网络时，打开连接器界面选择频道；不选频道则完全不改动机器的 AE 网络。
4. 连接器所在区块就是无线范围：区块内所有机器（含其他模组）都能被该工厂网络发现并打标签；循环工厂终端与样板供应器除外，必须接线。
5. 打标签之前不扫描、不入网、不搬运任何物品。
