# 循环进刻器

<BlockImage id="ae2lpt:loop_ticker" scale="5" />
<RecipeFor id="ae2lpt:loop_ticker" />

将绿色顶面对准相邻机器或支持随机刻的方块。方块支持六个方向。将任一形态单独放入工作台可在完整方块和线缆部件间互换。部件加速安装面正前方的相邻方块。

将进刻器接入有电的 ME 网络，空手右键打开界面，用数字框或滑条设置倍率。默认每服务端 tick 最多追加四次。每张加速卡使上限翻倍，四张最高 64。多台进刻器对准同一目标时，额外调用次数相加。目标仍需自己的原料和电力。
