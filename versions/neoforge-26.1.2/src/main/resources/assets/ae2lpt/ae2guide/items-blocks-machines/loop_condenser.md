# Loop Matter Condenser

<BlockImage id="ae2lpt:loop_condenser" scale="5" />
<RecipeFor id="ae2lpt:loop_condenser" />

Partition a Loop Storage Cell in a Cell Workbench and place it in the condenser's template slot. Connect the condenser to a powered ME grid with a free channel. Choose Matter Balls, Singularity or Trash in the condenser menu.

Every server tick the condenser extracts matching items from ME storage and sends products back to the network. Install an Inverter Card on the template cell to exclude marked items, or a Fuzzy Card to enable fuzzy matching. When the network cannot accept the result, the matter credit stays available for a later tick. Manual inputs work through the normal condenser slots.
