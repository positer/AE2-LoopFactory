# 高纯循环水晶

<ItemImage id="ae2lpt:purified_loop_crystal" scale="4" />
<RecipeFor id="ae2lpt:loop_crystal_seed" />

将循环水晶种子放进水中或晶体生长室。种子成熟后变成高纯循环水晶。消耗循环水晶的配方可以混用普通和高纯水晶。

晶体聚合器可用八份粉末、32 份沙和 51,200 AE 制作 32 颗种子。晶体粉碎器可消耗 8,000 AE，将任一种循环水晶磨成一份粉末。
