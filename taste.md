Explicit lexical channel blocks retain their own scope. Keep compiler keywords authoritative for native syntax highlighting and reserved names.

- On factory removal, cancel execution and preserve only actual owned resources in the original machine item. Keep resource segments separate when their aggregate exceeds `long`, preserve unresolved native records, subtract only accepted ME insertions, and never materialize expected recipe debt or copy cargo through a memory card.

- Shutdown queue fairness must preserve every native task, completion condition and final save. ### Terminal execution refresh contract (2026-09-13)

- Terminal redstone inputs restart on a rising edge, never on each powered tick. Installed-program changes cancel old runs immediately and defer one fresh start until an eligible owner tick. Compare program/binding content so same-code saves and unsaved drafts preserve progress.

## 2026-11-12 全向连接器拆除与状态写回

- 方块实体被移除时，坐标上的方块已经变成空气；凡是“由实体派生方块状态”的函数（本模组的 `updateBlockStateFromBlockEntity`），必须先在方块仍位于该坐标时才计算，否则 AE2 的 `markForUpdate` 会在拆除过程中把空气写回连接器，表现为首次破坏被挡回、频道丢失。
- 这类缺陷只能在真实服务端复现：`detach → GridConnection.destroy → validateGrid → Grid.create → setGrid → notifyStatusChange(POWER)` 是同步链，静态阅读看不出；诊断要先抓完整堆栈再改代码。
- 反向对照是必需证据：新增的“一次性破坏”断言必须用回退修复的制品跑一次并确认失败，再用通过版跑一次；两代各自留档。
- 方块实体的移除路径（`setRemoved`／`onChunkUnloaded`）不得写方块状态；区块卸载/重载与拆除共用该路径，改动要在两代同时验证。

## 2026-11-17 循环机器的原生复用与验收

- 继承非网络 AE2 方块实体时，网络能力注册不能替代 `clearRemoved → scheduleInit → onReady` 的初始化调度。节点销毁后不得用同一个 managed-node holder 重新 `create`；离线探针用真实隔离机器。
- 原生 `getUsedChannels()` 包含下游转送量；验收机器占 1 频道时按原生 controller route 区分本地需求与下游需求。零待机、零自身频道能耗与频道分配分别观察，不能用 idle=0 替代完整能耗结论。
- 网络转换遵循原生单位与额度，但不能复用会夹紧容量、填充实体输出槽的路径；只有网络实际接受的产物才扣余额。模板必须是已标记循环磁盘，反相卡需要真实持久化升级库存。
- 精确复用贴图以像素与几何合同验收：聚合器只改核心，进刻器区分世界与物品坐标模型。菜单沿用原生组件、升级面板与槽位背景，资源引用和 schema 验证不能替代真实窗口检查。
- 追加 tick 不修改世界时间、不取消第三方调度；每次重新取目标状态/实体并用 finally 释放重入保护。倍率按卡片倍数归一化保存，默认跟随最大值，玩家选择通过真实客户端消息验收。
- 进刻器页面只呈现输入框中的一份倍率数字，原生滑条不再单独显示当前值、范围或端点数字。拖动时立即更新同一个输入框，即使输入框仍聚焦；输入数字同步原生滑块位置。禁止重新引入 Minecraft 通用黑色滑条；AETextField 必须关闭原版 EditBox 边框，避免覆盖其原生 AE2 绘制。
- 进刻器滑轨固定横向；原生滑块旋转时必须连同事件坐标变换一起处理。界面高度压到 136px，控制行与背包标题仅保留约 4px，不以额外说明或重复数字填充留白。
