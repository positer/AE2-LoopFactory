# 2026-08-28 Release 0.0.1

## Scope

- Release name: `AE2 Light Optimizer 0.0.1`
- Git tag: `v0.0.1`
- Supported generations: Minecraft 1.21.1 / NeoForge 21.1.235 / AE2 19.2.17 and Minecraft 26.1.2 / NeoForge 26.1.2.94 / AE2 26.1.10-beta.
- Release assets are generation-qualified JARs; users must install only the matching artifact.

## Release gates

- Build both generation adapters and run all 56 tests in each.
- Launch both pinned NeoForge/AE2 data environments and verify transformed Mixin takeover bytecode.
- Confirm each JAR embeds version `0.0.1`, expected mod metadata, recipes, textures, GuideME pages, and Mixin configuration.
- Scan the staged release commit and final assets for secrets and forbidden ImmortalStorage/PCL runtime paths.
- Confirm local `main`, `origin/main`, and tag target the reviewed release commit before publishing GitHub assets.

## Rollback

- GitHub users can reinstall the previous available release asset; this initial formal release has no earlier formal asset, so rollback means removing the addon and returning to AE2's native calculation behavior.
- Runtime takeover is also disabled per network by disconnecting/removing both service blocks; without an active block, AE2 retains its original calculation and execution paths.
- No world migration or persistent schema conversion is performed by this release.
