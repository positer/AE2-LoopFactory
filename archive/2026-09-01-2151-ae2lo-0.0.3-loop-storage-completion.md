# 2026-09-01 21:51 +08:00 - AE2LO 0.0.3 Loop Storage completion

## Scope

- Completed the Loop Storage Cell family for NeoForge 1.21.1 / AE2 19.2.17 and NeoForge 26.1.2 / AE2 26.1.10-beta.
- Kept AE2 as the only hard mod prerequisite beyond the Minecraft/NeoForge platform. Optional storage addons are discovered only through AE2's key-type registry.
- Did not publish a GitHub release and did not deploy 0.0.3 into PCL instances.
- Corrected the specification's `13k` shaped-cell reference to the defined 16k core.

## Runtime implementation

- Added shared `LoopStorageTier`, `LoopStorageKeyUsage`, `LoopStorageUsage`, and `LoopStorageAccounting` types under `shared/.../storage/`.
- Implemented one shared capacity across every key type returned by `AEKeyTypes.getAll()`, using each type's native `getAmountPerByte()` value.
- Grouped stored entries by AE key type and accumulated quotient/remainder state before rounding the final partial byte. This prevents per-key over-rounding, preserves usable tail capacity, and keeps mixed item/fluid/addon accounting consistent.
- Preserved 63 types and AE2-equivalent per-type overhead for 1k through 256k. Removed the type limit for 1M through 256M. Represented the infinite tier explicitly with no capacity or type limit.
- Centralized both adapters' idle drain in `LoopStorageTier.idleDrain()`.
- Added version-local AE2 storage handlers, inventories, item tooltips, component persistence, status reporting, nested-cell protection, and client-only drive-model registration.
- Isolated all Minecraft client references behind `@Mod(..., dist = Dist.CLIENT)` in both adapters.

## Content and recipes

- Registered 22 Loop Storage items per generation: one housing, ten cores, ten finite cells, and one infinite cell.
- Added exactly 32 Loop Storage recipes per generation: one housing, ten cores, ten shaped cells, ten core-plus-housing shapeless cells, and one infinite-cell transform.
- Implemented the infinite-cell TNT conversion as data-driven `ae2:transform` with the `explosion` circumstance, 64 explicit 256M core ingredients, one housing, and one infinite-cell result.
- Each generation now packages 42 AE2LO recipes in total: 32 Loop Storage, eight Loop Crystal, and two network-block recipes.
- Added bilingual names, capacity/type tooltips, and English/Simplified Chinese GuideME pages. Each Loop Storage page indexes all 22 items and contains all 22 result recipe embeds, including the infinite transform.
